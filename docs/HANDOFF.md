# 外部条件交接

[English](HANDOFF.en.md) | 简体中文

更新:2026-11-03。这里只写**没有设备、账号、凭据或发布目的地就做不到**的事,以及每件事要记录什么。工程侧仍在推进的部分不在此列,那些写在 [STATUS](STATUS.md)。

## 一、一次 iOS 真机验收怎么做

1. 用 AltStore / SideStore 订阅 `https://raw.githubusercontent.com/laincat/AltStore/main/apps.json`,安装 **0.2.9(build 11)**;包未签名,签名由侧载工具在本机完成。
2. 首次启动后确认「我的」页显示 0.2.9/11,并把设备型号、iOS 版本、安装方式记下来。iOS 26 以下的设备装不上(最低系统 26.0),这种失败要单独记,不算缺陷。
3. 每一项都按「设备 + 版本 + 动作 + 期望 + 实际」四段记录,能截图就附截图。**不要**把模拟器结果当成这一节的证据。

## 二、移动端要记录的动作与判据

**下载与 Live Activity**:装一个可用漫画源,打开任意漫画的详情页,对一章点下载;期望锁屏与灵动岛出现下载进度,结束时变成完成态且不残留。

**断网阅读**:下载完成后开飞行模式,从「我的 → 下载」进入该章;期望每页都能翻,不出现网络错误。这一步是下载的核心承诺,模拟器上已经由 `testDownloadedChapterReadsWithNoServer` 覆盖,真机仍要自己看一遍。

**播放、字幕与续播**:进入「视频」的在线源,搜索一个条目,播第 1 集;期望有画面与声音(静音键状态要记录),字幕可选英文/中文/关闭,退出后重新进入从原位置继续。**画中画与后台音频**单独记:切到桌面后是否继续发声、是否出现画中画按钮。

**失败后重试**:把某一章的下载弄失败(例如中途断网),打开「我的 → 下载」应看到「没有下载完成」分组,行内有失败原因与「重试」;点重试后该章进入下载列表。这条路径现在有单元与模拟器用例,但真机上的失败原因(断网、后台被系统回收)只有设备能给。

## 三、账号与媒体服务器

**Bangumi**:在「我的」登录 Bangumi,打开一部有放送信息的作品,确认放送日历显示的是真实数据而不是空列表。

**TMDB**:填入 API Key,确认详情页出现中文简介与封面;Key 失效时要看到可读的错误,而不是一直转圈。

**标准 AI**:在「AI」里填一个 OpenAI 或 Anthropic 兼容端点与 Key,发一句话;期望收到回答,并且取消能停下。**流式**目前不是网络流式:Core 侧 `stream` 为 `false`,整包返回,这一点在记录里要写明,不要把整包当流式。

**Magpie 插件**:安装一个供应商插件并登录,确认模型目录能列出、能对话、能取消;刷新凭据后重启 App,确认仍处于登录态。

**媒体服务器**:准备可访问的 Jellyfin / Emby / Plex 与账号,确认服务器摘要、库列表与播放地址可用。没有服务器时这一项保持未验证,不用假数据代替。

## 四、签名、公证与发布目的地

**iOS 签名安装**:当前 IPA 未签名。需要 Apple Developer 账号与描述文件才能产出可直接安装的签名包;在那之前,侧载签名由使用者的工具完成。

**macOS 分发**:`scripts/package-macos.sh` 产出的是 **ad-hoc 签名**的 `.app`,只保证本机可运行。要在别的机器上直接打开,需要 Developer ID 证书签名并公证(notarization),这两步都需要账号与凭据。

**Windows 分发**:包未签名,首次运行会出现 SmartScreen 提示。消除它需要代码签名证书。

**Nekophage 远端**:仓库没有 remote,本地包不发到任何地方。要公开发布需要先决定放哪儿(GitHub Release、自有站点或不做),这一步只能由你决定。
