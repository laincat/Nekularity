# 外部条件交接清单

[English](HANDOFF.en.md) | 简体中文

本页给需要真机、真实账号或外部服务的人工验收步骤。已有工程证据与最新基线见 [STATUS.md](STATUS.md)，未验证项全表见 [UNVERIFIED.md](UNVERIFIED.md)。

## 一、确认验收构建

1. 先核对要验的包：公开最新包是 `v0.4.9` / build `31`（`01016b5`，Core `2bafd88`）；若要验 `0.4.9` 之后的改动（如默认 HTTPS ATS 或后续重构），须取对应提交的 CI 未签名 IPA 重新签名安装，不要用旧包验证新修复。
2. 现有 loopback 夹具仅限同机进程访问，不供真机直接连电脑的 `127.0.0.1`；真机验收使用可达媒体或本机导入，不擅改网络、代理或防火墙。

## 二、真机操作与观察判据

| 项 | 验收动作与判据 |
|---|---|
| 签名安装与冷启 | 安装后首次启动、添加/查看源、切后台并杀进程重开，确认资料与设置保留 |
| 视频续播与字幕 | 播放时长 > 10 秒的带字幕视频，播过 7 秒后退出并重开，确认位置恢复与中英字幕切换/关闭实际画面可见 |
| 画中画、后台与锁屏 | 启动 PiP 确认小窗持续推进；退回主屏与锁屏后确认播放不断，返回 App 状态正常 |
| 实际扬声器 | 播放确有音轨的素材，确认人耳实际听到声音且音量/外放切换正常 |
| 下载 Live Activity | 触发一次下载及一次失败重试，在真机锁屏与灵动岛观察状态变化与重试后消失 |

## 三、真实账号与后置服务

- **标准 AI**：页面**已接入流式响应**并支持响应头即时拒收（`b81b52d` / CI `42193319262`）。使用真实 OpenAI / Anthropic 兼容端点验证模型列表、流式增量输出、触发 `max_tokens` 截断提示、取消请求及重启后 Keychain 凭据恢复；取消是否停止服务端计费需看服务端日志或用量。
- **Magpie 供应商包**：安装用户自备或官方模板供应商包，验证登录、刷新、目录、首段流式输出、取消与重启恢复；凭据不写入仓库或日志。
- **后置服务**：Bangumi、TMDB、Pixiv、Jellyfin / Emby / Plex 需各自真实账号或服务器；在线弹幕等后置插件能力不作为本阶段发布前置。
